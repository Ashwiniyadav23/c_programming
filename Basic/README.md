What: A C program is a plain text .c file. A compiler (GCC) turns it into machine code. Every program starts from main().
Why: C talks almost directly to hardware. Knowing how to compile gives you control that Python or JavaScript hide from you.

| Part                 | Meaning                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------ |
| `#include <stdio.h>` | Includes the Standard Input/Output library.It provides functions like `printf()`and`scanf()`. 
|
| `int main()`         | The entry point of the program. Execution starts from the `main function.                     
|
| `printf(...)`        | Prints formatted output to the screen (console).                                                
   
| `return 0;`          | Returns control to the operating system and indicates that the program executed successfully.          |
